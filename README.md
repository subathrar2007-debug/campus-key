# 🏆 Campus Key - 1st Prize Winning Project
### One ID. One Tap. Connected Campus.

> Award-winning NFC-powered campus ecosystem | Built by students of Arunachala College of Engineering for Women

## 🌟 What is Campus Key?
Your college ID is just plastic? We made it smart! Campus Key turns a normal ID card into a connected campus pass.

Note: The ID card shown in screenshots is a dummy/sample (Sunrise College) created for prototype demonstration to protect real student data.

- **Secure NFC ID:** No personal data on the tag, only a secure token. Privacy first!
- **Admin Console:** Student Management, Attendance (85% tracker), Gate Pass, Hostel & Transport.
- **Tamper-proof:** Every tap is recorded & auditable.
